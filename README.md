# CI603-Data-Mining
University of Brighton Year 3 Computer Science with AI module. Received a first (70%). This project investigates how the 11 features of the wine impact the quality of it and finds any patterns in the data. Multiple methods of data mining were used in this project including, Dimensionality Reduction, Support Vector Machine, Naive Bayes and FP-Growth.

Dataset was found on https://archive.ics.uci.edu/dataset/186/wine+quality
